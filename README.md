# Maison Élise Studio — Premium Beauty & Wellness Landing Page

A responsive, single-page HTML/CSS/JS template for salons, estheticians, skincare studios, spas, massage therapists, and wellness brands.

## Quick start
1. Unzip the package.
2. Open `index.html` in a browser, or run a local static server from this folder (for example `python -m http.server 8000`).
3. Customize the brand, services, prices, links, images, contact details, and policies before publishing.

No build step or framework is required. Google Fonts and photography load from external URLs, so an internet connection is needed for those assets.

## Included files
- `index.html` — complete page structure and demo copy.
- `styles.css` — design tokens, responsive layouts, and component styles.
- `script.js` — mobile navigation, subtle reveal motion, testimonial scroll controls, footer year, and explicit booking-placeholder handling.
- `privacy.html`, `terms.html` — editable legal-page starter content.
- `CUSTOMIZATION.md` — buyer setup checklist and content map.
- `LICENSE.txt` — template usage and third-party asset notes.

## Highlights
- Responsive layout for desktop, tablet, and mobile.
- Semantic HTML, keyboard focus styles, skip link, and reduced-motion support.
- Accessible FAQ accordion using native `details`/`summary`.
- CSS design tokens for global colors, typography, and page width.
- Service cards and editable treatment price list.
- Testimonial scroller controls and mobile menu interaction.
- Booking CTA clearly identifies its placeholder URL.
- SEO description and social-sharing metadata.

## Important before publishing
Demo ratings, statistics, testimonials, prices, promotion, address, hours, phone, and email are placeholders. Replace them with truthful information. Images use remote URLs and must be checked for licensing/usage rights for your intended commercial deployment. No real booking engine or map embed is included.
